## Question

[手机实测](07-phone-check.md)时用户决定：界面布局和交互照方案 H，但视觉另做一版设计，牌身渲染方式也放到这次一起定。

在方案 H 的布局和交互上（侧栏在右、竖屏转置、吸附拖动加点箭头，见[移动的界面原型](10-move-ui-prototype.md)），出几版不同的视觉方案，和用户一起选：

- 配色和背景：现在是绿色麻将桌。
- 侧栏、按钮、消息卡片、新局面板的样子（新局面板和胜利卡片的内容见[定开局与结束流程](06-start-and-end-flow.md)）。
- 牌身：用素材原样的 SVG（带模糊滤镜）、去掉滤镜，还是先画成位图，或者换一种牌身画法。每版都要在手机上看帧率，参考数据见 07 号票：iPhone 上 SVG 原样 61 fps。
- 选中、同牌高亮、连线、▼ 提示、翻成牌背的样子。

规则、交互和流程都已经定了，这张票只改长什么样。

术语见 [CONTEXT.md](../../../CONTEXT.md)。

## Answer

**选「夜雀」：深色雀庄，墨绿桌面、深灰侧栏、金色数字和标记；牌身用 CSS 画，象牙色牌面底下一道翠绿厚边；翻掉的格只留一个淡淡的凹槽，不再显示牌背。** 原型在 [prototype/](../prototype/README.md) 的 `?skin=night`（样式在 `skins.css` 的 `skin-night` 一节），另外三套（经典绿桌、和纸、糖果）留着对照。

1. **桌面**：墨绿色径向渐变，中间亮、四周暗（`#173a30` → `#0c1f1a` → `#08130f`）。
2. **侧栏**：深灰底 `#16191d`，左边一条细分隔线。
   - 四个计数是细线框里的金色数字（`#e2b55a`），标签是灰色小字。
   - 提示、撤回、赖子是深灰按钮加细描边；赖子模式时变紫（`#5b2fa6`）。
   - 消息卡片是深灰底，左边一条颜色边：警告金、错误红、成功和选配法绿、赖子紫。卡片里的按钮是金底黑字。
   - 「新局」是细线框按钮，「玩法」是灰色小字。
3. **新局面板**：深色面板，选中的难度按钮和「开局」按钮是金底黑字；放弃当前这局的红字用浅红（`#ff8a80`）。
4. **牌身**：不用 `Front.svg`，用 CSS 画：
   - 象牙色底（`#f3eee1`），圆角约牌宽的 12%；
   - 牌面图案贴在上面，约占宽 82%、高 80%，略偏上；
   - 底下一道翠绿厚边（`#1f7a57`，约牌宽的 8%），再加一层投影。
   - 这样也定了牌身渲染：不用 SVG 模糊滤镜，比原样 SVG 更省。
5. **翻掉的格**：不显示牌背，只留一个淡淡的凹槽（很淡的白色底加 1px 细边）。白板是象牙色的牌，和凹槽一眼能分开，所以白板仍然不加框。这推翻了[牌阵界面与交互原型](04-board-ui-prototype.md)里"翻成深色牌背"的定稿。
6. **标记**：
   - 选中：金色细框、往上浮 3px、金色外发光；场上其他牌照旧变暗，只有同牌亮着。
   - 连线：金色。提示的 ▼：金色，带发光。
   - 移动能停的格：金色箭头框。
   - 赖子模式的虚线外框：紫色。

**没有测的**：夜雀在手机上的帧率没有单独测。它去掉了模糊滤镜，应该不会比原样 SVG（iPhone 61 fps）更卡，实现以后在手机上看一眼即可。
