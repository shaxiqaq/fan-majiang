# 定存档与记忆

Type: grilling
Status: resolved
Assignee: zhuoxuan233
Map: [翻麻将：从想法到规格书](../map.md)

## Question

和用户一起决定：刷新、关闭页面再打开以后，游戏要记住哪些东西。

- **未完成的牌局**：要不要保留。如果保留，范围是只保留当前棋盘，还是连撤回历史、生成时的解（提示兜底要用）、用时、步数、已用赖子数、已用提示数一起保留。
- **难度**：上次选的预设或自定义数值要不要记住。
- **用时**：页面不在前台或者关闭的那段时间，要不要继续计时。
- **存在哪里**：只存在本机浏览器里就够了吗？联网已经划在范围之外。存档读不出来，或者游戏更新后存档格式变了，怎么处理？

背景：有了「移动」以后（见[定移动机制](08-move-mechanic.md)），牌在棋盘上的位置会变，撤回历史里也有移动；只记哪些格空了、不足以还原局面。赖子和提示都不限次数，用了会记下来；步数撤回不减。设置里已经没有提示开关了。见[定发牌与死局策略](03-deadlock-policy.md)。

术语见 [CONTEXT.md](../../../CONTEXT.md)。

## Answer

**未完成的牌局完整保留在本机浏览器里，刷新、关掉页面再打开，和没关过一样；另外记住上次选的难度。用时只算页面在前台的时间。** 两轮问答，用户十条全选推荐项。

1. **保留什么**（Q1 选甲）：存档就是"当前这一局"，内容包括：
   - 开局牌阵：136 张各在哪格、哪三张是赤五。存牌阵本身，不存随机种子，所以以后改了发牌算法，旧存档照样能读。
   - 生成解：提示兜底要用。（[定难度三档](11-difficulty-tiers.md)改为存「存下的解」：互换法发的牌存求解器找到的含移动解。）
   - 整条撤回历史：翻牌、移动、用赖子翻牌都在里面；恢复以后能一路撤回到开局。
   - 步数、已用赖子数、已用提示数、用时、本局难度。

   不选"只存棋盘"，是因为那样恢复以后撤回不了、提示兜底失效，和已定的规则矛盾。手机浏览器在后台回收页面很常见，不保留就会经常丢局。
2. **难度**（Q2 选甲）：记住上次选的预设档或自定义数值，下次新开一局默认用它。在哪里选、中途改什么时候生效，归[定开局与结束流程](06-start-and-end-flow.md)。
3. **用时**（Q3 选甲）：只算页面在前台、看得见的时间。切到别的标签页或 App、锁屏、关掉页面都暂停，回来接着算；胜利时停住。不检测"人在前台但走开了"，照样算。原型现在用的是钟表时间（含后台），要改。
4. **历史战绩**（Q4 选甲）：不记。只记当前这一局，不做通关局数、最快用时之类的统计，和"仅作参考，不排名"一致。
5. **存在哪里**（Q5 选甲）：只存在本机浏览器里。换设备、换浏览器接不上；清浏览器数据、无痕模式会丢，接受。不做导出和导入。
6. **进行到一半的状态**（Q6 选乙）：只存已经完成的操作，下面这些都不存：
   - 选中、赖子模式、求解器正在思考：恢复以后都没有。
   - 等玩家从几种配法里选一对的移动：作废，牌串回原处，和"玩家没选就作废"一致。

   只多存一样：**已经给出的提示结果**（▼ 标的那一对或那次移动，或者"已经无解"卡片和它的"撤回到走错之前"按钮）。恢复以后照样显示，一直留到下一次翻牌或撤回，不会白白多记一次提示。求解中页面就关了，结果丢掉；已用提示数按下时已经加一，不退回。
7. **胜利以后**（Q7 选乙）：存档打完了也不清，开了新局才换掉。重新打开页面遇到已经胜利的局怎么显示，交给[定开局与结束流程](06-start-and-end-flow.md)；这样那张票如果允许胜利后撤回，关页面也不会丢。
8. **读不出来或格式过期**（Q8 选甲）：存档带版本号。遇到下面任何一种情况，就丢掉这一局、开新局，消息卡片说一句"上一局的存档读不出来，已经开了新局"：
   - 版本号对不上；
   - 数据坏了；
   - 从开局牌阵重放历史操作时，有一步不合规则。

   难度读不出来就回到"普通"，不提示。不写旧格式的转换。
9. **两个标签页**（Q9 选甲）：不处理，各玩各的，后存的覆盖先存的。
10. **什么时候存**（Q10 选甲）：每次操作完成（翻牌、移动、赖子、撤回、按提示）马上存，改了难度也马上存。用时在页面隐藏、关闭时存，平时每隔几秒存一次。最多丢几秒用时，不会丢操作。

术语同步更新到了 [CONTEXT.md](../../../CONTEXT.md)：新增「用时」「存档」两个词条。
