# 定开局与结束流程

Status: resolved
Assignee: zhuoxuan233
Blocked by: 04, 05

## Question

参考[牌阵界面与交互原型](04-board-ui-prototype.md)做出的界面和[定存档与记忆](05-save-and-memory.md)的结论，和用户一起决定一局从开始到结束的流程：

- **打开页面时**：[定存档与记忆](05-save-and-memory.md)已经定了要完整保留当前这一局（打完了也保留到开新局）。还要决定：有未完成的存档时，是直接接着玩，还是先问一句；没有存档时，是直接开一局，还是先显示开始画面；存档里的局已经胜利了，是停在胜利画面，还是直接开新局。
- **用时从什么时候开始算**：牌阵一显示就算，还是玩家第一次操作才算。用时只算页面在前台的时间，见[定存档与记忆](05-save-and-memory.md)。
- **新开一局**：入口放在哪里。如果当前这局还没打完，要不要先确认放弃。
- **选难度**：在哪里选，是开新局时选还是在设置里选。中途改难度，是马上开新局，还是从下一局开始生效。
- **重开本局**（同一个牌阵）：还要不要这个功能？撤回本来就能一路退回开局，区别只在于用时、步数、已用赖子数、已用提示数要不要清零。
- **胜利画面**：显示哪些内容（用时、步数、已用赖子数、已用提示数、难度）；之后能做什么（再来一局、留下来看棋盘）；胜利以后还能不能撤回。

界面已经定为侧栏布局（见[牌阵界面与交互原型](04-board-ui-prototype.md)的答案）：棋盘旁边一根竖栏，放四个计数、提示/撤回/赖子三个按钮和消息卡片。新开一局、选难度的入口和胜利画面，都要放进这个布局里。

死局时怎么处理已经在[定发牌与死局策略](03-deadlock-policy.md) 里定好：显示一条不挡棋盘的提示，附上撤回、赖子、提示三个快捷入口。这张票不再讨论。

术语见 [CONTEXT.md](../../../CONTEXT.md)。

## Answer

**打开页面直接恢复存档，没有存档就直接按"普通"发一局，并在侧栏说明玩法；开新局从侧栏的「新局」按钮进，难度在弹出的新局面板里选，放弃确认也在这个面板里；胜利只在侧栏卡片里显示，不挡棋盘，之后仍然能撤回。** 两轮问答，用户九条全选推荐项。

**已经写在 [CONTEXT.md](../../../CONTEXT.md)、这次没再问的**：
- 用时从玩家第一次操作（点牌、拖牌串、按提示或赖子）起算，见[定存档与记忆](05-save-and-memory.md)。
- 当前这局走过至少一步、还没胜利时，开新局要确认放弃。
- 不做"重开本局"，想重来就一路撤回。
- 难度在开新局时选定，打到一半不能改。
- 胜利以后仍然能撤回，开新局之前都算同一局。

1. **打开页面时有没打完的存档**（Q1）：直接恢复，接着玩，不问。
2. **第一次打开、没有存档**（Q2）：
   - 直接按"普通"发一局，不做开始画面。
   - 侧栏消息卡片里用三四行写玩法：连线最多拐一次弯、移动牌串配同牌、赖子、提示。
   - 这段说明只在第一次自动出现。
3. **打开页面时存档里的局已经胜利**（Q3）：
   - 停在胜利状态：棋盘全是牌背，侧栏显示胜利卡片（见第 6 条）。
   - 撤回照样能用。
   - 不自动开新局。
4. **开新局的入口**（Q4）：
   - 侧栏放一个常驻的「新局」按钮，在提示、撤回、赖子下面，样式弱一档，免得误按。
   - 按下后在棋盘中间弹出新局面板：上面是三档难度，下面是自定义滑条，最下面是「开局」按钮。
   - 当前这局要确认放弃时，面板里多一行红字"当前这局还没打完，开局就会放弃它"。确认就合并在面板里，不另弹第二个确认框。
   - 点面板外面或按 ✕ 就取消。
5. **难度在哪里选**（Q5）：
   - 只在新局面板里选，不另做设置页。
   - 面板打开时默认选中上次用的难度（存档里记的，见[定存档与记忆](05-save-and-memory.md)）。
   - 自定义滑条默认收起，点"自定义"才展开。
6. **胜利画面**（Q6）：
   - 不用全屏弹窗，就是侧栏的消息卡片，写"全部翻完！"。
   - 卡片列出用时、步数、已用赖子、已用提示和难度。
   - 卡片里有一个「新局」按钮，打开新局面板；这时开新局不用确认。
   - 棋盘保持全是牌背，撤回照常能用。撤回以后胜利卡片消失，用时接着算。
   - 不加动画和音效。
   - 侧栏平时也用一行小字显示本局难度。
7. **玩法说明还能再看**（Q7）：侧栏底部、「新局」旁边放一个小字链接「玩法」，点了就在消息卡片里重新显示第 2 条那几行。
8. **自定义滑条怎么标**（Q8）：
   - 内部取值 0–2（见[定难度三档和困难档的发牌办法](11-difficulty-tiers.md)），但不把数值显示给玩家。
   - 两端写"简单"和"像随机发牌"，中间标出简单、普通、困难三个刻度。滑块到刻度附近就吸附，认成那一档。
   - 停在别处就显示"自定义"，不写数值。
   - 所以对玩家显示的难度只有"简单 / 普通 / 困难 / 自定义"四种。存档里照旧记滑条值。
9. **打开新局面板时有操作在进行**（Q9）：
   - 先把这些都退掉：等选配法的移动作废、牌串滑回原处；赖子模式退出；正在想的提示作废，已用提示数不退回。
   - 然后再打开面板。在面板里取消，也不恢复退掉的状态。
   - 用时照常在走，打开面板不算操作。
